# Vocabulário mínimo

Os termos que vão aparecer nas conversas com a equipe depois do treinamento. Só o que a gestão precisa para acompanhar — o [glossário completo](../../dia-1/entregaveis/07-glossario.md) está nos materiais do Momento 2.

| Termo | Em uma frase | Por que importa para a gestão |
| ----- | ------------ | ----------------------------- |
| **Agente de código** | Uma IA que lê e escreve arquivos do projeto, não só responde perguntas | Ele executa; a decisão continua sendo de quem pede |
| **Repositório** | A pasta do projeto com todo o histórico de mudanças | É onde a evidência mora; se algo não está lá, não existe |
| **Commit** | Um ponto salvo no histórico, com uma frase explicando o que mudou | Permite voltar atrás e entender a sequência de decisões |
| **Branch** | Uma linha de trabalho paralela, para não mexer no que está no ar | Trabalho em andamento não afeta o que já funciona |
| **Pull request (PR)** | O pedido de incorporar uma mudança, com descrição e evidência | É o **registro de entrega**: o que a gestão lê para aceitar |
| **PRD** | O documento com problema, escopo, não escopo e critérios | O artefato da etapa 1 e 2; sem ele não há aceite possível |
| **Critério de aceite** | Uma afirmação verificável sobre o que o sistema faz | Transforma "está bom" em sim ou não |
| **Escopo / não escopo** | O que entra agora e o que fica explicitamente de fora | O freio contra o projeto crescer sem decisão |
| **`AGENTS.md`** | O arquivo com as regras que o agente deve seguir naquele projeto | O padrão da área vira instrução, não recomendação |
| **Teste automático** | Uma verificação que roda sozinha e falha quando algo quebra | É a evidência que não depende de alguém lembrar de conferir |
| **Validação** | Rodar as verificações e conferir os critérios antes de entregar | A diferença entre "funciona na demonstração" e "está pronto" |
| **MCP** | Uma conexão que dá ao agente acesso a um sistema externo | Toda conexão nova é uma decisão de permissão — pergunte se é só leitura |
| **Skill** | Um procedimento salvo que o agente repete do mesmo jeito | Padroniza tarefas recorrentes entre pessoas diferentes |
| **Template de projeto** | Um ponto de partida com estrutura e regras já prontas | Faz projetos de pessoas diferentes nascerem iguais |
| **Definição de concluído** | A lista combinada do que precisa estar feito para algo ser "pronto" | O acordo que evita discussão caso a caso |

## Três frases que valem correção

**"O agente errou."** Na maior parte das vezes o agente respondeu exatamente ao que foi pedido — o pedido é que estava aberto. Vale perguntar: o que estava escrito quando isso foi solicitado?

**"Está pronto, só falta testar."** Então não está pronto. Validar faz parte da tarefa, não é etapa posterior.

**"Foi a IA que fez."** Quem responde pela entrega é a pessoa que a assina. Isso não muda com a ferramenta.
